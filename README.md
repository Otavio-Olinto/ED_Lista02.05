# ED_Lista02.05
## Cálculo de MDC

Este desafio consiste em criar uma aplicação, em Java, que receba dois números naturais e calcule o maior divisor comum(MDC) entre eles.

```
Requisitos do projeto:

1. Arquitetura MVC;
2. O cálculo deve ser realizado por uma função recursiva;
3. O cálculo deve utilizar a fatoração por número primos;
4. Declarar, via comentário, a condição de parada da função.
```
